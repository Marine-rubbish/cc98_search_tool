# CC98 帖子搜索

在指定版面里搜索主题标题和全部可读回复。关键词只出现在后排楼层时，也能找到对应主题。

工具通过你已登录的 Chrome 标签页只读访问 CC98，结果和进度保存在本机。支持 CC98 官方站点和浙大 WebVPN。

> 当前为本地开发版，需要手动加载 Chrome 扩展，尚未发布到 Chrome 应用商店。

## 使用前准备

- macOS、Linux 或 Windows
- Node.js 24 或更新版本
- Chrome 116 或更新版本
- 已登录 CC98 的 Chrome 标签页

## 开始使用

### 启动搜索页

macOS 或 Linux：

```bash
./start-cc98-search.sh
```

首次运行如提示没有执行权限，先运行 `chmod +x start-cc98-search.sh`。macOS 会自动打开 Chrome；Linux 会在终端显示搜索页地址。

Windows 用户可以双击 **`start-cc98-search.cmd`**，也可以在命令提示符或 PowerShell 中运行：

```powershell
.\start-cc98-search.cmd
```

各平台也可以在项目目录使用统一命令：

```bash
npm run open
```

首次运行会自动安装依赖并启动后台服务。重复运行会复用已经启动的服务。默认地址为 <http://127.0.0.1:9876>，后台日志位于 `.cc98/server.log`。

Windows 启动入口和浏览器打开逻辑已经实现，但尚未在真实 Windows 环境完成验证。

### 停止搜索服务

macOS 或 Linux：

```bash
./stop-cc98-search.sh
```

Windows 可以双击 **`stop-cc98-search.cmd`**，也可以运行：

```powershell
.\stop-cc98-search.cmd
```

各平台还可以使用 `npm run stop`。停止服务不会删除任务进度、结果或本地配置；服务未运行时重复执行也不会报错。使用自定义数据目录时，可追加 `--data-dir <目录>`。

### 加载 Chrome 扩展

首次使用需要手动加载一次：

1. 在 Chrome 打开 `chrome://extensions`。
2. 开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本项目的 `extension` 文件夹。
5. 打开并登录 CC98，回到本地搜索页。

扩展会自动绑定本地服务，不需要填写端口或配对码。页面显示「Chrome 已连接」后即可搜索。

更新扩展代码后，请在扩展管理页点击一次「重新加载」。当前扩展版本为 **0.2.3**。

### 发起搜索

1. 输入关键词。
2. 选择版面。默认的「就业」包含求职广场和实习兼职。
3. 按需调整并发数和每秒请求数。
4. 点击搜索，结果会在扫描过程中持续出现。

历史范围很大的版面可能需要运行较长时间。请保持电脑唤醒，并保持 Chrome 和 CC98 标签页打开。

### 组合多个关键词

在搜索方式中选择「分面组合 · 多关键词」，输入 `字节 杭州 Linux C++`，点击「生成分组」。本地词典会建议公司、地点和方向等条件组，已知别名会显示在词下方，支持修改或删除。

- 组内默认取并集（OR），例如 Linux 或 C++ 任一命中即可；改成 AND 则要求两者都出现。
- 组间默认取交集（AND），例如公司、地点、技能都满足。也可以改成任一组满足。
- 交集按整帖判断，标题和不同楼层可以分别满足条件。结果显示每个已命中词的片段与楼层链接。

未知词保留在普通词组，未知英文短语保留内部空格。逗号、顿号、分号和换行用于分隔词；空格可分隔词典认识的词。这是可编辑的词典建议，不解析任意自然语言，也不调用大模型。开始搜索前请检查「实际搜索条件」。

每次最多 20 个逻辑词，每词最多 5 个别名。一个词及其别名始终按 OR 判断。单关键词模式仍把输入当作一个完整关键词。

任务开始后条件固定，修改条件需新建任务。满足当前条件后就会停止读取该帖，因此 OR 结果不保证列出全帖所有命中词，也不能直接把旧结果改成新的交集筛选。

## 搜索结果如何产生

- 扫描所选版面的历史主题，不依赖 CC98 站内关键词搜索。
- 检查主题标题、主楼和全部可读回复。
- 标题或回复满足完整搜索条件后返回该主题，不再读取后续楼层。
- 同一主题只保留一条结果，跨版置顶会按主题实际所属版面判断。
- 默认使用字面包含匹配，英文不区分大小写。
- 支持常用 UBB 和 Markdown 文本，保留引用内容。
- 图片、附件、音视频和已删除楼层不参与匹配。

分面组合不会按关键词分别请求正文，同一段文字只解析一次。词同现只表示整帖中出现了这些字面表达，不判断否定语气或公司与职位之间的关系。

目录信息齐全、标题未命中且最多 10 楼的短帖，会在正文读完后按来源页批量核对。同页 20 个稳定短帖可用 20 次正文请求加 1 次目录核对完成，目录发现的请求另计。无法批量核对时逐帖读取详情，发现变化则重新扫描；读取失败仍列为问题项。

默认并发数为 `20`，每秒最多发起 `10` 次请求。界面允许的并发范围为 `1–20`，请求频率范围为 `1–50`。

## 中断与恢复

任务进度实时写入本机 SQLite。已完成的主题、命中结果和目录位置不会因为页面关闭或服务重启而丢失。

- 访问令牌过期时，扩展会自动刷新绑定的 CC98 标签页一次；确认仍是同一账号后继续请求。
- 扩展短时断开时，任务会等待连接；同一账号重连后继续当前轮次。
- 服务重启后会保留运行意图；同一账号的扩展重新连接后，任务从保存位置继续。
- 手动暂停、手动取消或切换账号后不会自动续跑。
- 自动恢复失败时，请重新登录 CC98，再检查扩展连接。

电脑休眠、关机或 Chrome 退出期间无法继续读取论坛。恢复环境后，任务可以从本地进度接续。

## 状态说明

| 页面状态 | 含义 |
| --- | --- |
| 扫描中 | 正在读取目录或主题 |
| 等待扩展 | 扩展连接中断，正在等待同账号重连 |
| 等待登录 | 自动续期未恢复登录，等待重新登录 |
| 已暂停 | 用户暂停、账号变化或其他原因使任务停止 |
| 已取消 | 用户取消任务，已有结果仍保留 |
| 扫描结束 · 覆盖未验证 | 已发现的主题都有结论，但无法证明动态目录绝对无遗漏 |
| 扫描结束 · 有读取问题 | 仍有目录或主题未能正确读取 |

“扫描结束”不等于证明没有遗漏。CC98 使用偏移分页，扫描期间的顶帖、删帖和移帖可能改变目录。工具通过重叠分页、两遍目录复查和短页尾部确认减少遗漏，但仍会明确显示“目录完整性未验证”。

读取失败、空正文或权限受限的主题会列为问题项，不会当作“没有匹配”。

## 真实长跑诊断

本地服务更新到最新代码、Chrome 扩展重新加载且没有其他任务运行后，可以手动启动：

```bash
npm run soak -- --keyword "麒麟软件"
```

默认扫描就业版面，并发 `20`、每秒 `10` 次请求、运行上限 `90` 分钟。参数可以调整：

```bash
npm run soak -- --keyword "麒麟软件" --boards 235,459 \
  --concurrency 12 --rate 6 --duration-minutes 120
```

使用 `npm run soak -- --help` 查看全部参数。诊断记录保存在 `.cc98/soak/`。普通进度只记录计数，错误明细仅在变化时写入 `errors_changed`。监控器意外退出后，可以运行 `npm run soak -- --attach JOB_ID` 继续观察原任务。

发生未恢复中断时，在 Trae 中要求 AI 读取 `.cc98/soak/latest.json` 指向的 `repair-request.md`，再根据真实证据修复和回归。

## 数据与隐私

- 论坛账号密码不会被读取或保存。
- 论坛访问令牌只保留在 Chrome 会话中，不会传给本地服务。
- 本地服务只监听 `127.0.0.1`，页面、CLI 和扩展连接均有本机鉴权。
- `.cc98/` 保存任务、历史、命中片段和本地连接配置，不保存全量帖子正文。
- `.cc98/` 已加入 `.gitignore`，不要手动公开其中的文件。

## 常见问题

**页面一直显示“等待扩展自动连接”**

确认扩展已加载，Chrome 中有已登录的 CC98 标签页。升级扩展后，需要在 `chrome://extensions` 点击「重新加载」。

**WebVPN 已登录，为什么仍提示登录问题**

WebVPN 登录和 CC98 登录是两层认证。请确认 WebVPN 内的 CC98 页面也处于登录状态，然后刷新该标签页。

**修改本地代码后会立即生效吗**

- `web/` 页面代码：刷新搜索页后生效。
- `src/` 本地服务代码：重启服务后生效。
- `extension/` 扩展代码：在扩展管理页重新加载后生效。

**结果很多，页面没有全部显示**

页面最多展示 `1000` 条。需要完整数据时使用 CLI 导出。
